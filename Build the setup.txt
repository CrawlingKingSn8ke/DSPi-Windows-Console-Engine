Build the DSP engine with DSPi-Software-DSP/build.ps1, then build the APO with scripts/build-apo.ps1.
Publish DSPiConsole as self-contained win-x64. The Console embeds the APO and installer code.
Pass the official PowerShell ZIP as DspiPowerShellArchive and keep PowerShell-runtime.zip next to DSPiConsole.exe.
The local-development admin and worker scripts pin the tested APO SHA-256. Review and update those pins for a rebuilt DLL.
See README.md for the commands.
